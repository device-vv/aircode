# AIRcode v0.2.0

## English

First working Windows x86_64 portable release.

- Real UTF-8 file opening, editing, saving, Unicode selection, IME, clipboard, and undo/redo.
- Native Kimi Code integration with `k3.1-pro`, `k3.1-pro-highspeed`, K3, and other official model IDs.
- Required thinking for K3.1 Pro and `low` / `high` / `max` reasoning effort.
- Streaming reasoning and answer content, cancellation, and new sessions on model changes.
- Kimi Platform, DeepSeek, RouterAI, and custom OpenAI-compatible profiles.
- API keys stored in the OS credential store, never in settings or release files.
- Optional document or selection context and light/dark themes.

Download `aircode-windows-x86_64.zip`, extract it, and run `aircode.exe`. Rust is not required. The executable is unsigned, so SmartScreen may ask for confirmation. Verify the published SHA256 file.

Validation: 27 tests passed, Clippy passed, Windows UI exercised with real file saving and a local streaming SSE server. A live paid provider account was not used. LSP, Tree-sitter, Git, terminal, and autonomous agents are not included yet.

## Русский

Первый рабочий portable-релиз для Windows x86_64.

- Реальное открытие, редактирование и сохранение UTF-8 файлов, Unicode-выделение, IME, буфер обмена и undo/redo.
- Нативная интеграция Kimi Code с `k3.1-pro`, `k3.1-pro-highspeed`, K3 и другими официальными model ID.
- Обязательный thinking для K3.1 Pro и уровни reasoning `low` / `high` / `max`.
- Потоковые reasoning и ответ, отмена запроса и новая сессия при смене модели.
- Профили Kimi Platform, DeepSeek, RouterAI и OpenAI-compatible.
- API-ключи только в системном хранилище ОС, не в настройках или файлах релиза.
- Контекст документа или выделения по выбору, светлая и тёмная темы.

Скачайте `aircode-windows-x86_64.zip`, распакуйте и запустите `aircode.exe`. Rust не нужен. Цифровой подписи пока нет, поэтому SmartScreen может запросить подтверждение. Проверьте SHA256-файл.

Проверка: 27 тестов и Clippy пройдены, Windows UI проверен с сохранением файла и локальным SSE-сервером. Реальный платный аккаунт не использовался. LSP, Tree-sitter, Git, терминал и автономные агенты пока не входят.
