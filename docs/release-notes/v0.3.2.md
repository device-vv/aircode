# AIRcode v0.3.2

## Русский

Portable-сборка для Windows x86_64. Распакуйте `aircode-windows-x86_64.zip` и запустите `aircode.exe`; Rust не требуется.

- Вкладки файлов, прокрутка редактора, компактное меню и изменяемые панели.
- Встроенный терминал с системной оболочкой в папке проекта.
- Обновлённая подсветка языков, включая Rust, Python и Dart; определение проектов Flutter.
- История и черновик ИИ-чата сохраняются отдельно для каждого проекта. Доступны подтверждаемая очистка и автоматическое сжатие длинного контекста.
- Подсказки кода ИИ включаются в настройках; Tab принимает подсказку, Escape отменяет.
- Исправления закрытия с несохранёнными изменениями и диалогов на русском и английском языках.
- Обновление сборки: журнал агента больше не растягивается из-за содержимого файлов; после восьми действий работу можно продолжить кнопкой. В панели проекта доступно создание файла с любым именем и расширением. Терминал открывается в корне проекта автоматически. Исправлено автодополнение и добавлено сообщение при ошибке провайдера или ключа.
- Защита файлов `.env` расширена на варианты вроде `.env.production` и `.env.local`.

Проверены автоматические тесты, Clippy, локальная Windows-сборка и запуск окна. Терминал проверен с PowerShell; ИИ-клиент и сжатие — с локальным тестовым сервером. Реальный платный API не использовался. Исходный вылет на другом компьютере при переносе между мониторами повторить не удалось; Linux и macOS в этой сборке не проверялись и пакеты для них не публикуются.

При включённых ИИ-подсказках код вокруг курсора отправляется выбранному провайдеру; большая история может отправляться для сжатия. Запросы могут быть платными. Терминал и команды агента выполняются с правами пользователя. Установщик не подписан; Windows может показать предупреждение SmartScreen. Проверить архив можно по приложенному SHA-256.

## English

Windows x86_64 portable build. Extract `aircode-windows-x86_64.zip` and run `aircode.exe`; Rust is not required.

This release adds file tabs, editor scrolling, resizable panels, an integrated project terminal, improved Rust/Python/Dart highlighting and Flutter project detection, project-scoped AI chat history with compaction, and opt-in AI code completion.

The updated build keeps the agent activity panel compact, allows continuing after the tool-step limit, adds new-file creation with arbitrary extensions, opens the terminal in the project root, and improves completion scheduling and error feedback.
Agent file protection also covers `.env.production`, `.env.local`, and similar variants.

Automated tests, Clippy, the Windows build and window startup were checked. Terminal tests used PowerShell, while AI tests used a local mock server rather than a paid provider. The original crash on another multi-monitor computer could not be reproduced. Linux and macOS were not runtime-tested for this release and no packages are published for them.

AI completion sends surrounding code to the selected provider; large chat histories may also be sent for summarization. Provider charges may apply. Terminal and agent commands run with user permissions. The executable is unsigned. A SHA-256 checksum is provided with the archive.
