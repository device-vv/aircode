# AIRcode v0.3.0

## English

Windows x86_64 portable release with project editing and project-aware AI tools.

- Full project explorer with filesystem watching and incremental Tree-sitter highlighting for 15 popular languages.
- Resizable project/editor/agent panels, Unicode editing, clipboard context menus, and saved layout settings.
- Custom AIRcode title bar and icon, no console window, and verified minimize, maximize/restore, and close behavior.
- English and Russian interfaces, including a Russian-locale suggestion.
- Collapsible reasoning, message copying, horizontal input scrolling, and streaming cancellation.
- Project agent tools for listing, reading, searching, writing, creating directories, moving, deleting, and commands.
- Ask every action / Ask important only / Full access modes, write diffs, approvals, and an activity log.
- Command timeout and cancellation, path escape and protected-file checks, and an eight-step agent limit.
- Native Kimi Code with K3.1 Pro, Kimi Platform, DeepSeek, RouterAI, and OpenAI-compatible profiles.

Download `aircode-windows-x86_64.zip`, extract it, and run `aircode.exe`. Rust is not required. The executable is unsigned, so SmartScreen may ask for confirmation. Verify the published SHA256 file.

Validation: 42 tests and Clippy passed. This replacement for the same v0.3.0 release fixes blocking file/folder dialogs, Windows title-bar dragging, and window redraw after repeated minimize/maximize/restore cycles. Real file and project opening, multi-monitor dragging, 10 window-state cycles, 25 menu cycles, and unsaved-change confirmation were exercised. The complete agent loop was tested through the UI with a local mock API in all three permission modes, including approval, denial, file writing, and final responses. Test credentials were removed. A live paid provider account was not used.

LSP, debugging, Git, integrated terminal, multi-tab editing, and signed installers are not included. Shell commands run with user permissions and are not sandboxed. macOS and Linux are not published runtime releases.

## Русский

Portable-релиз для Windows x86_64 с редактированием проекта и ИИ-инструментами.

- Дерево всего проекта, отслеживание файлов и инкрементальная Tree-sitter подсветка 15 популярных языков.
- Изменяемые панели проекта/редактора/агента, Unicode-ввод, контекстные меню буфера обмена и сохранение раскладки.
- Фирменная строка заголовка и иконка, отсутствие консоли, проверенные сворачивание, разворачивание/восстановление и закрытие.
- Английский и русский интерфейсы с предложением переключения для русской локали.
- Сворачиваемые рассуждения, копирование сообщений, горизонтальная прокрутка ввода и остановка потока.
- Инструменты проекта: список, чтение, поиск, запись, папки, перемещение, удаление и команды.
- Режимы разрешений для всех/только важных действий/полного доступа, diff, подтверждения и журнал.
- Тайм-аут и остановка команд, защита от выхода из проекта и доступа к секретным файлам, лимит восемь шагов.
- Нативный Kimi Code с K3.1 Pro, Kimi Platform, DeepSeek, RouterAI и OpenAI-совместимые профили.

Скачайте `aircode-windows-x86_64.zip`, распакуйте и запустите `aircode.exe`. Rust не нужен. Цифровой подписи пока нет, поэтому SmartScreen может запросить подтверждение. Проверьте SHA256-файл.

Проверка: 42 теста и Clippy пройдены. Этот пакет заменяет прежний v0.3.0 и исправляет блокировку диалогов файлов/папок, перетаскивание строки заголовка и перерисовку после повторных сворачиваний и восстановлений. Проверены реальные файлы и проект, перетаскивание между мониторами, 10 циклов состояния окна, 25 циклов меню и подтверждение несохранённых изменений. Полный цикл агента протестирован через UI с локальным mock API во всех трёх режимах: разрешение, запрет, запись файла и финальные ответы. Тестовые ключи удалены. Реальный платный аккаунт не использовался.

LSP, отладка, Git, встроенный терминал, вкладки и подписанные установщики пока не входят. Shell-команды выполняются с правами пользователя и не изолированы. Релизы для macOS и Linux не опубликованы.
