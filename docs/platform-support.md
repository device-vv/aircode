# Поддержка платформ AIRcode

Требование проекта: AIRcode должен работать на Windows, Linux и macOS. Новые возможности проектируются для всех трёх систем, включая терминал, хранение истории и взаимодействие с редактором. Платформенные особенности изолируются за общим интерфейсом; непроверенные платформы явно указываются в результатах проверки.

Перед выпуском изменения проверяются на каждой поддерживаемой системе. Существующая матрица CI включает Windows, Linux и macOS; успешная компиляция сама по себе не заменяет проверку интерфейса, терминала и ввода на соответствующей системе.
